# Practice Hub

https://github.com/naooo7/compact-results-hero

Work directly on the existing Fundamental. project.

IMPORTANT:

Do NOT create a new project.

Do NOT rebuild the app from scratch.

Do NOT use or reference the old FastLearner project.

Preserve the existing Fundamental. branding and current working components.

Preserve the existing desktop left sidebar and mobile bottom navigation.

Preserve existing routes unless a change is explicitly required below.

Do not redesign unrelated screens.

The Practice page should function as the central hub with these 5 modes:

Fundamental.

Drill Soal

Latihan Soal

Try Out

Read

For modes that contain subcategories, use a selection-card layer:

Cards are vertical, one per row.

Full-width rectangular cards inside the content container.

Rounded corners.

Compact but comfortable height.

Icon on the left.

Title and short description in the middle.

Progress/status on the right when relevant.

Do not use a 2-column card grid.

Fundamental. has a special flow:
Practice → Fundamental. → Subject Selection → Learning Path.

Subject Selection should contain:

English

Mathematics

Bahasa Indonesia

Logika

Do not add an extra decorative bar or redundant section between Fundamental. and the subject cards.

Only make structural changes required for this specification.
Do not modify Question, Result, Progress, Needs Review, Try Out, Read, or backend/authentication yet.
